# ADR-005: Авто-монтаж (нарезка, субтитры, B-roll, версии под площадки)

**Status:** Accepted

## Context

Нужен программный, безручной способ: (а) вырезать лучшие моменты из длинного сырого видео, (б) прожечь субтитры, (в) собрать версии под разные аспектные соотношения и лимиты длины конкретных площадок. Technology Audit проверил специализированные SaaS (Opus Clip, Submagic, Shotstack) и self-hosted open-source варианты на базе FFmpeg.

Ключевой вывод аудита: у Opus Clip и Submagic сильная API-интеграция, но программный доступ закрыт за платными планами — Business-план Opus Clip "по запросу" (нет прозрачной цены), Submagic Business+API $69/мес. CapCut — NOT_AVAILABLE, официального API для этой задачи не существует вовсе. Shotstack — бесплатный лимит только 20 минут рендера, не годится для продакшна без платной подписки. FFmpeg self-hosted решения (например `artbyjazi/autoclip`) — AVAILABLE, нулевая лицензионная стоимость, требуют больше инженерной работы на старте.

## Decision

**FFmpeg-based self-hosted пайплайн**, отправная точка — `artbyjazi/autoclip` как референс/основа, адаптированная под нужды ROMAN RAW (детекция моментов на основе уже полученного транскрипта из ADR-004, а не собственного STT-шага). Выполняется внутри того же исполнителя, что и остальной пайплайн (Cloud Routine / GitHub Actions runner — см. ADR-003).

## Consequences

- Нулевая ежемесячная стоимость лицензии — соответствует бюджетным ограничениям владельца, в отличие от Submagic ($69/мес) или Opus Clip Business.
- Больше инженерных усилий на старте (нет готового API "просто вызвать") — принимается как компромисс за отсутствие подписки.
- Качество авто-детекции моментов и субтитров нужно валидировать вручную на первых роликах — если самодельный пайплайн даёт заметно хуже результат, чем Opus Clip/Submagic, пересмотреть решение (зафиксировано как открытый пункт в Implementation Plan, не блокирует старт).
- **Shotstack** держится в уме как опция для финального шага рендера конкретных аспектов, если FFmpeg-пайплайн окажется слишком трудозатратным по времени разработки — не выбран сейчас, но не исключён полностью.
- **CapCut исключён из плана полностью** — публичного API не существует, неофициальные reverse-engineered обёртки не рассматриваются как продакшн-надёжные.
