# ADR-004: Транскрипция

**Status:** Superseded (пересмотрено по решению владельца — см. Decision v2 ниже)

## Context

Первый содержательный шаг пайплайна ROMAN RAW и голосовых команд в Telegram — получить текст (с таймкодами, для видео) из аудио. Technology Audit изначально проверил три платных облачных варианта: OpenAI Whisper API ($0.006/мин), AssemblyAI ($50 бесплатных кредитов), Deepgram Nova-3 ($200 бесплатных кредитов, самая низкая цена из трёх).

## Decision v1 (первоначальное, отклонено)

Deepgram Nova-3 как основной сервис.

## Decision v2 (текущее, принято)

Владелец явно отклонил любой сторонний облачный сервис транскрипции — даже при наличии бесплатного кредита, чтобы не создавать очередной внешний аккаунт/зависимость. Вместо этого используется **self-hosted открытая модель Whisper** (веса модели — открытая лицензия MIT, никакого API-ключа, аккаунта или карты не требуется):

- Реализация: `whisper.cpp` (лёгкая, на C/C++, хорошо работает без GPU) или `faster-whisper` (Python-обёртка, оптимизированная под CPU/GPU) — выбор конкретной реализации фиксируется при первом практическом запуске (обе бесплатны и open-source, разница в удобстве интеграции с остальным TS/Node.js стеком — ADR-001).
- Используется единообразно и для транскрипции сырого видео в пайплайне ROMAN RAW, и для расшифровки голосовых команд, присылаемых боту в Telegram.
- Выполняется на той же инфраструктуре, что и FFmpeg-монтаж (ADR-005) — self-hosted раннер/Cloud Routine, а не отдельный сервис.

## Consequences

- Полностью бесплатно навсегда, ноль сторонних аккаунтов — соответствует явному требованию владельца "не плодить подписки/регистрации".
- Компромисс: требует вычислительных ресурсов на стороне исполнителя (CPU/GPU-время), а не просто HTTP-вызова к готовому API — больше инженерной настройки на старте, чем у Deepgram.
- Качество распознавания русской речи у Whisper хорошее из коробки (multilingual-модель), но точность стоит проверить практически на первых голосовых командах и реальных исходниках видео, прежде чем полагаться на неё как единственный источник текста.
- Deepgram/AssemblyAI остаются в резерве в Technology Audit как справочная информация, но не выбраны — пересмотреть только если self-hosted Whisper не будет справляться по скорости/качеству на практике.
