# ADR-004: Транскрипция

**Status:** Accepted

## Context

Первый содержательный шаг пайплайна ROMAN RAW — получить текст с таймкодами из сырого видео, чтобы выделить "лучшие моменты" и сгенерировать субтитры. Technology Audit проверил три варианта: OpenAI Whisper API ($0.006/мин, без бесплатной квоты), AssemblyAI ($50 бесплатных кредитов, ~185–238 ч), Deepgram Nova-3 ($200 бесплатных кредитов, не сгорают, ~433 ч бесплатно, далее $0.0043–0.0077/мин — самая низкая цена из трёх).

## Decision

**Deepgram Nova-3** как основной сервис транскрипции. **AssemblyAI** — резервный вариант (встроенная саммаризация может пригодиться позже для авто-выделения моментов). **OpenAI Whisper API** — fallback на случай недоступности обоих (простой, предсказуемый посекундный биллинг).

## Consequences

- $200 бесплатного кредита Deepgram, который не сгорает, покрывает пилотный период (сотни часов видео) без реальных трат — соответствует требованию "ограниченный бюджет".
- REST API у всех трёх вариантов подходит для безручной облачной автоматизации — интеграция не завязана на конкретный UI.
- При исчерпании кредита Deepgram остаётся самым дешёвым PAYG-вариантом ($0.0077/мин monolingual) — переключение на fallback не требуется по умолчанию, только при реальном сбое сервиса.
