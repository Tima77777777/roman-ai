# ADR-006: Публикация на площадки

**Status:** Accepted

## Context

Нужна программная публикация на YouTube Shorts, Instagram Reels, TikTok, Facebook Reels, X, Telegram. Technology Audit проверил прямые официальные API каждой платформы и платные агрегаторы (Metricool $53/мес, Ayrshare $149/мес, Buffer Free с неподтверждённой поддержкой Reels).

Ключевые находки:
- **YouTube Data API v3** — AVAILABLE, бесплатно, ~100 загрузок/день — с запасом.
- **Facebook Reels API** — AVAILABLE, бесплатно, но требует оформления бренда как Facebook Page (не личный профиль).
- **Instagram Graph API** и **TikTok Content Posting API** — оба технически бесплатны, но требуют предварительной модерации: Instagram — App Review Meta (2–4 недели), TikTok — аудит приложения (2–6 недель), до прохождения которого контент через API не становится публичным.
- **X (Twitter) API** — PAID без бесплатного пути с февраля 2026 (pay-per-use, центы за пост при низком объёме, но обязательна карта).
- Агрегаторы (Metricool/Ayrshare) — платные, дороже, чем прямые API + собственная оркестрация.

## Decision

Подключать **YouTube Data API v3** и **Facebook Reels API** сразу в Phase 1 — оба бесплатны и не требуют модерации. **Подать заявки на Instagram App Review и TikTok Content Posting API аудит в первый же день Фазы 0/1**, не дожидаясь готовности остального пайплайна — это единственный по-настоящему время-критичный пункт (недели ожидания). **X API** — не приоритет первой недели, подключить по мере готовности (P2). Оркестрация между площадками — **n8n Community Edition (self-hosted)** на дешёвом VPS, дёргающий напрямую перечисленные официальные API, вместо платных агрегаторов.

## Consequences

- До прохождения модерации Instagram/TikTok первые недели публикация на эти две площадки будет ручной — это надо явно спланировать, а не считать MVP полностью автономным с первого дня.
- n8n self-hosted требует своего VPS (~$5–7/мес) — принимается, дешевле любого из платных агрегаторов.
- X API отложен — экономит обязательную привязку карты и ежемесячные микро-траты до момента, когда площадка станет реально нужна.
- Buffer Free (бесплатно, но Reels-поддержка не подтверждена документацией) не выбран как основной путь — можно пилотно перепроверить позже, не блокирует MVP.
